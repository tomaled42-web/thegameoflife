# Игра в жизнь 3.0

Личный трекер привычек в виде ролевой игры. Работает без сборки и без сервера: обычные HTML, CSS и JS.

## Публикация на Netlify

1. Открой app.netlify.com → **Add new site** → **Deploy manually**.
2. Перетащи туда всю папку `Игра в жизнь 3.0`.
3. Открой выданную ссылку на телефоне и добавь на главный экран:
   - iPhone (Safari): «Поделиться» → «На экран „Домой“»;
   - Android (Chrome): меню ⋮ → «Установить приложение».

Чтобы выложить обновление, снова перетащи папку в раздел **Deploys** того же сайта.

## Данные

Весь прогресс хранится в браузере на устройстве (localStorage, фото — в IndexedDB). Телефон и компьютер не синхронизируются: перенос делается через «Настройки → Скачать копию / Восстановить». Копию стоит скачивать время от времени.

## Структура

- `index.html`: каркас страницы
- `css/app.css`: все стили
- `js/engine.js`: игровая логика (опыт, импульс, щиты, награды, достижения, боссы)
- `js/view-*.js`: экраны
- `sw.js`, `manifest.webmanifest`, `icons/`: установка на главный экран и офлайн-режим
